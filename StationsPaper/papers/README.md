Downloaded: 29 of 167 references (25 October 2026). The download used only open links listed by OpenAlex and Semantic Scholar. Wiley/AGU, Oxford (GJI), Elsevier, Science, PNAS, Royal Society, and Europe PMC refused scripted requests, so most AGU papers are missing even when they are free to read. 92 missing references are marked open access (gold, hybrid, bronze, green, or diamond) and can be fetched by hand from the DOI link.

The PDFs are copyrighted publisher or author copies for private reading. Git ignores them (`papers/*.pdf` in `../.gitignore`); this index is tracked.
